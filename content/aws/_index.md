## Introduction

The AWS playbook is a highly-opinionated guide for managing AWS accounts and resources.
These are the practices that have been working for OMSF; these may not be best for large-scale organizations, but they are what have been working for us.
The goal here is to have this be a resource that makes it easier for new projects to align their AWS setups with what we recommend.

Organization of this playbook is heavily inspired by the [Diàtaxis](https://diataxis.fr/) framework for technical documentation.
Diàtaxis splits technical documentation into four categories: tutorials, how-to guides, explanations, and reference material.
This playbook currently contains how-to guides and explanations.
At this point, we don't see a need for tutorials (which differ from our how-to guides in that they are focused on teaching, rather than on accomplishing a task).
For reference material, we recommend visiting the main AWS documentation.
